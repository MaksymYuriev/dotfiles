Хто за що відповідає

Головна ідея: ⌥ і ⌃ належать редактору й терміналу, вікнами керує Meh, застосунками ⌘.

Meh = ⌃⌥⇧Вікна й workspaces (AeroSpace), хоткеї застосунків (Raycast)Voyager: тримати E або I. MacBook: тримати Caps
Hyper = Meh+⌘Перемістити вікно (AeroSpace)Voyager: E/I + лівий thumb ⌫ (hold = ⌘). MacBook: Caps + ⌘
⌘Застосунки й macOSVoyager: D, K або hold лівого thumb ⌫
⌥ ⌃Neovim і zshVoyager: S/L = ⌥, A/; = ⌃
F18 F19Мова: завжди EN / завжди UAVoyager: нижні кути. MacBook: тап лівого ⌘ = EN, правого ⌘ = UA

Chordal Hold: hold на home row або E/I рахується, коли друга клавіша на іншій руці. Тому Meh для правої руки береш з E, для лівої з I. Та сама рука теж працює, але треба довше потримати.

Voyager

Під клавішею дрібним підписом те, що вона робить при утриманні. Порожні клавіші на шарах пропускають дію з базового шару.

Meh утримання ⌘ ⌥ ⌃ ⇧ home row mods Шар 1 символи Шар 2 навігація Шар 3 медіа F18/F19 мова

Шар 1 легко вивести: верхній ряд це Shift+цифри з ряду вище (! під 1), на home row дзеркальні дужки: відкривальні зліва, закривальні справа на тому самому пальці. Символи працюють тільки на EN, тож перед кодом F18.

Типова розкладка на G9

Три колонки на одному workspace: nvim | Claude Code | dev server.

Відкрий три вікна Ghostty (⌘N). Фокус на крайнє праве, Meh+; потім h: два праві стануть одне над одним. Ширину підкрути через Meh+R.

Не використовуй зелену кнопку чи нативний fullscreen: такі вікна AeroSpace не бачить. Вкладки Ghostty теж не дружать з AeroSpace, замість них нові вікна.

Якщо щось зламалось

Вікно зниклоaerospace list-windows --all покаже, на якому workspace воно живе
Розкладка дивнаMeh+; потім r. Вікно поводиться як плаваюче: Meh+Space
Конфіг AeroSpaceПеречитується сам при збереженні. Вручну: aerospace reload-config
Meh друкує літериПотримай E/I трохи довше або бери з іншої руки, ніж літера
F18/F19 пищатьKarabiner → Devices: для Voyager увімкнено Modify events
vim не реагує на UAКоманди з : тільки латиницею. F18 і повтори
Відкат прошивкиKeymapp → Flash → оригінальний .bin з Oryx
